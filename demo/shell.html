What you are looking at

Every screen, style and piece of formatting here is the application itself. Only the database is replaced, by a handful of sample notices held in this page, so nothing you do can reach a real masjid or a real family.

The notices are invented, and deliberately look it. “Fulan ibn Fulan” is the Arabic equivalent of “John Doe”, the masjids are named “Sample”, and every address is an example street. Nothing here names a real person, a real institution or a real place.

  • Try “Near me”. It asks permission first and explains where your location goes. A browser inside a preview frame is not allowed to read a real position, so it uses a fixed point in downtown Toronto. Everything after that, the distances, the radius, the erase on opting out, is the real code.
  • Follow a masjid. Stored in your own browser, exactly as in the product. Nothing is sent anywhere.
  • Alerts show as unavailable. That is the honest state before a project is configured, not a broken preview. Notifications to a closed page need a server credential.
  • Reports are accepted and discarded. There is no administrator queue behind this page.
  • One notice has no name, because that family did not approve sharing it. The name is never written rather than written and hidden.

Not shown here: the coordinator console, where a masjid publishes and corrects notices, and the administrator screens for verification and reports. Those need sign-in, so they only run against a real project.
